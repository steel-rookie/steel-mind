# 기수 진단 보고서 (교육 담당자용)

여러 사람의 진단 기록을 이름 없이 모아, 교육 과정을 어떻게 고칠지 보는 보고서입니다. 설치 없이 브라우저로 엽니다.

1. **기록 모으기**: Unity 결과 화면의 "기록 폴더" 버튼을 누르면 `steelmind_runs/run_*.json`이 있는 폴더가 열립니다. 판이 끝날 때 자동으로 저장되며, 결과 화면의 "구분: 신입/경력" 버튼으로 비교 기준을 정합니다.
2. **불러오기**: `index.html`을 열고 "실제 진단 기록 불러오기"에서 JSON 여러 개를 고릅니다. Unity 기록과 HTML 시연 기록을 함께 불러올 수 있습니다.
3. **인쇄/PDF**: "인쇄 / PDF 저장"을 누르면 PART마다 쪽이 나뉩니다.

- 기록 형식: `schemas/steelmind-run-v2.json` (예시: `schemas/examples/`)
- 기록에 없는 분석(판단 전 확인 행동, 교대 인계)은 "기록 없음 · 다음 버전에서 측정"으로 표시하고 문장을 만들지 않습니다.
- "가상 데이터 포함"은 발표·시연용 가상 기수입니다. 가상만 있으면 맨 위에 "사실 아님" 경고가 붙고, 실제와 섞이면 섞였다는 경고가 붙습니다.
- `demo_bank.js`는 HTML 시연의 상황 정의입니다(가상 기수 만들기와 시연 기록 읽기에만 씀). Unity 기록은 기록 안의 역량·사건 정보를 씁니다.
- 개인 결과는 본인·사수용이고, 이 보고서는 익명 집계용입니다. 인사 평가·배치에 쓰지 않습니다.
